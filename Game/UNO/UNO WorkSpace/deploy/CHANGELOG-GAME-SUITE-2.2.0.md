# LayUDown Game Suite 2.2.0

- 明日方舟 UNION ARENA 牌桌：生命区去掉外围边框和 1—7 计数格，改为按实际生命卡数量动态渲染的叠放展示。第一张在最上方完整可见，其后每张从上一张下方露出 38%—60%，卡牌保持 7:5 的原始宽高比，不压缩、不裁切。对手的生命区沿用对手半场整体旋转 180° 的规则，方向自动镜像。
- 协议与服务器：房间状态 `ua:state` 新增 `life`（`you` / `opponent`，每张牌含 `id` 与 `cardId`）。`cardId` 为 `null` 表示盖着的牌，盖着的牌的身份不会发送给任何客户端（包括牌的主人和对手）。房间开局时会把各自洗好的牌组前 7 张作为盖着的生命卡；大厅阶段生命区为空。
- 牌桌顶部栏压缩：高度约 28px（手机约 32px），按钮和头像变小，房间号与人数合并为"房间 XXXXXX · n/2 人"，手机上也保持可见。
- 大厅更新记录新增 v2.2.0 条目；版本号升至 2.2.0。
- 未改动：UNO、日本将棋、账号与认证、卡牌目录与卡图、Nginx 及端口配置。

## 已知限制

- 开局仍被服务器拒绝（卡牌类型、费用、触发图标与效果文本尚未逐张核实），所以真实对局中生命区目前不会出现卡牌；发牌与盖牌逻辑已由单元测试覆盖，但尚未在真实联机对局中验证。
- 生命卡的"翻开"目前只有服务器状态支持，客户端没有触发入口。
- 起手发牌顺序（先取生命卡再抽手牌）为按官方规则推定，尚未对照规则书逐项核对。
