# LayUDown Game Suite 2.3.0

## 更新

- 明日方舟 UNION ARENA 可以联机开局。侧栏新增"我的牌组"：从卡牌目录用 ＋/－ 选卡（或"快速组牌"），提交后服务器按规则书校验：主牌组恰好 50 张 + 3 张 AP 卡、同一作品代码、同卡号最多 4 张。通过校验后才能"准备"；改动牌组会取消准备。
- 开局流程（服务器权威，规则书 Preparing to Play）：各自洗牌 → 随机决定先手 → 各抽 7 张起手牌 → 换牌（先手先决定，可重抽一次：手牌放到牌库底，抽 7 张新牌，再洗牌）→ 各取牌库顶 7 张盖着放入生命区 → 先手开始第 1 回合。
- 盖着的生命卡的身份不会发送给任何客户端（包括牌的主人）；对手的手牌和双方牌库只发送数量。
- 协议扩展（旧事件保持兼容）：`ua:state` 新增 `game`（先手、当前回合方、换牌决定者、手牌数、牌库数）与 `hand`（仅发给本人）；新增事件 `ua:mulligan`；移除永远为假的 `rulesReady` / `rulesMessage`。`startAllowed` 由真实状态计算。
- 对局中有人离开房间：留下的玩家回到大厅（牌组保留、准备状态清空），可等待新对手。对局中掉线 30 秒内可恢复到完全相同的对局状态，超时按原有机制移出房间。
- 卡牌目录预览图可点击放大：桌面端从预览图位置平滑飞到屏幕中央，手机端原地缩放淡入；支持 Esc、右上角关闭按钮和点击遮罩关闭，焦点回到预览图，遵守"减少动态效果"设置。
- 牌桌中间新增一条 1px 半透明灰色分隔线（不占布局空间、不拦截鼠标）。
- 关键字说明去掉了多余的标记和提示，文字内容不变。
- 大厅更新记录新增 v2.3.0 条目；版本号升至 2.3.0。
- 未改动：UNO、日本将棋、账号与认证、卡牌目录与卡图、Nginx 及端口配置。

## 已知限制

- 开局后只能完成起手、换牌、生命区和进入第 1 回合；出牌、能量与 AP 支付、移动、攻击、伤害与触发结算、胜负判定尚未实现，也没有桌面手牌区（手牌显示在侧栏）。
- 卡牌目录没有类型、费用、触发、效果字段，所以服务器不校验这些，也不会执行任何卡牌效果。
- 规则书中"特殊 / 颜色 / 最终触发各最多 4 张"的构筑限制需要触发类型数据，目前不校验。
- 先手由服务器随机决定（规则书写的是"剪刀石头布等方式"）。
- 编号 7071、7084 两张卡没有图片，不能放入牌组。
