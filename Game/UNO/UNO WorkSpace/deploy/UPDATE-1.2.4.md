# LayUDown 1.2.4 网页更新

- 登录页标题显示 LayUDown；登录后大厅、游戏入口和浏览器标签恢复为 UNO。
- 登录页和大厅不显示“在线联机卡牌游戏”副标题。
- “关于我”是 `/about` 独立页面，微信和支付宝收款码纵向展示，不再使用支付切换按钮或悬浮窗口。
- UNO 规则、在线房间、账号和联机功能保持不变；个人资料名称仍为 LayUDown。
- 网页更新包：`release/layudown-web-1.2.4.tar.gz`。不包含 Windows 安装程序和 Android APK。

部署和回滚步骤见 `deploy/README-1.2.4.md`。
