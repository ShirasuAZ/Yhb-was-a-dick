该文件包含标准 108 张牌面组成的 14×8 精灵图。项目只使用本地副本，不依赖外部图片站点。

`plus10.svg` 和 `card-back.svg` 是为本项目制作的派生素材，沿用相同的白色外框、黑色牌面、圆角和四色标识视觉语言。
