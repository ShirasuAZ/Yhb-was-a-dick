# 卡牌能力框架

卡牌自身的能力文本（登场时、退场时、启动主要、持续效果、费用变化……）写成数据，由规则引擎执行。还没写进来的卡，继续用放大图里的「卡牌效果」手动结算。

| 文件 | 作用 |
| --- | --- |
| `types.ts` | 能力的数据格式：时机、条件、费用、步骤。 |
| `dsl.ts` | 编写能力用的小工具（`onPlay`、`chooseOwn`、`bp`、`activateMain`……）和常用条件。 |
| `cards.ts` | 能力表：卡号 → 能力列表。每条上方抄一遍卡面原文，方便核对。示范卡和红色卡写在这里，其它颜色在 `cards-yellow.ts`、`cards-blue-a.ts`、`cards-blue-b.ts`、`cards-purple.ts`，由 `cards.ts` 合并。 |
| `registry.ts` | 把卡牌目录和能力表合成引擎用的上下文（`cardContext`）；`isAutomated` 判断一张卡能否全自动结算。 |

## 引擎怎么跑能力

- **时机**：登场时（包括突进、触发、效果让卡登场）、退场时（按规则书第 13 页"退场"的定义：战斗、BP 降到 0 以下、效果写明"退场"）、攻击时、未被阻挡时、阻挡时、战斗胜利时、攻击结束时、移动到前线 / 能量线时、主要阶段开始时、结束阶段开始时，以及事件卡的使用。
- **队列**：同一时刻发动的能力先排队；回合方的先结算，同一玩家有多个时由他选择顺序（规则书"多个能力同时发动"）。
- **选择**：步骤里的"选择……"会暂停，等玩家（或电脑）从列出的选项里选；"最多 N 张"可以不选；只有不超过最少张数的选项时自动选上。"可以……"会先问"是 / 否"。
- **续接**：能力结算完后，被打断的流程接着进行。例如攻击时能力 → 询问阻挡 → 战斗 → 败者的退场时能力 → 胜者的战斗胜利能力 → 冲击伤害 → 攻击结束时能力。
- **持续效果**：每次变化后重新计算 BP、关键字、能量产出；手牌里的费用变化在出牌时按当前局面计算。
- **持续时间**：本回合中（结束阶段清除）、直到下一个我方回合开始（起始阶段清除）。
- **启动主要**：支付费用（自身转为休息、弃手牌、支付 AP、自身退场），检查发动条件和"每回合 1 次"（按场上每张卡分别记录）。

## 添加一张卡

1. 在 `cards.ts` 里按卡号加一项，上方注释抄卡面原文。
2. 用 `dsl.ts` 的工具描述它，例如：

   ```ts
   // 米莎：【登场时】选择我方场上的最多1张所需能量不高于2的角色，本回合中，BP+2000。
   "UC01BT/ARK-1-002": [onPlay(chooseOwn("target", { max: 1, filter: energyCostAtMost(2) }), bp(chosen("target"), 2000))],
   ```

   现有工具表达不了的效果，可以用 `{ do: "run", fn, text }` 直接写代码（里面不能再要求选择）。
3. 在 `Game/UNO/UNO WorkSpace/tests/unit/arknights-abilities.test.ts` 里加一个测试：摆好局面，执行能力，检查结果和卡面一致。
4. 对照卡图核对一遍 `Cards/cards.json` 里的文本（这些文本是从卡图识别的）。

能力写进来以后，这张卡就算"全自动"（`isAutomated`），可以放进电脑对手的预设牌组。

## 其它颜色新增的引擎机制

- 时机：攻击阶段结束时、放回手牌时、离场时（退场、放回手牌、移除、置于卡组底）。
- 标记：不会退场、只能在能量线登场、必须尽可能攻击、不会受到 BP 降低、在前线也产生能量、改名（突进用）、不会被 BP 高于某值的角色阻挡、只能被特定特征的角色效果选择。
- 「本回合下一张从手牌使用的卡」的 AP 减免和活跃登场（`nextPlay`、`nextPlayLowBp`）；按卡名的「1回合只能发动1次」（`turnMarks`）。
- 事件的使用条件（`useCondition`，不满足时报 `EVENT_CONDITION`）；由对方来选的选择步骤（`chooser: "opponent"`）；背面朝上压在角色下的卡（`faceDown`，对对手隐藏）。
- 效果让生命区清空时判负（`loseIfNoLife`）。
- 退场的替换效果（`kind: "replaceSideline"`，煌、Ace）：角色因战斗或效果将要退场时（BP 降到 0 以下、支付费用、手动操作除外），先问拥有者是否「改为……」，问完前角色留在场上，正在结算的能力也暂停；拒绝了就照常退场。
- 「当此卡牌置于场外时」（`onEnterSideline`，博士）：每次结算后检查场外里新出现的这类卡，不论是从场上、手牌、卡组还是生命区进去的。
