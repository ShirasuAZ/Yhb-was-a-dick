## 1. 游戏概述

UNION ARENA 是两人对战的集换式卡牌游戏。每名玩家用自己组的 50 张牌组和 3 张 AP 卡对战，**先让对手的生命区清空的一方获胜**。

一局游戏里，玩家轮流进行回合。每个回合分为起始、移动、主要、攻击、结束五个阶段：在能量线上布置角色和场地产生能量，用能量和 AP 打出卡牌，再用前线的角色攻击对手。

---

## 2. 卡牌

卡牌分为四种：**角色**、**场地**、**事件**（这三种组成牌组），以及不放进牌组的 **AP 卡**。本卡池共有 161 种角色、5 种场地、28 种事件，颜色有黄、红、蓝、紫四种。

### 2.1 卡面要素

| 要素 | 说明 |
| --- | --- |
| **所需能量**（左上角数字） | 使用这张卡的条件：能量线上产生的、与这张卡**同颜色**的能量总数，必须**不少于**这个数字。能量不会被消耗。**所需能量的颜色就是这张卡的颜色。** |
| **消费 AP**（ACTION 数字） | 使用这张卡要支付的 AP 数：把这么多张活跃的 AP 卡转为休息。 |
| **卡名** | 能力里用〈卡名〉指代，例如〈陈〉。 |
| **特征** | 例如“特征：龙门”“特征：企鹅物流”，能力和突进用 [特征] 指代。不是每张卡都有特征。 |
| **作品名 / 作品代码** | 卡号里 `ARK` 这一段就是作品代码，组牌时 50 张必须相同。 |
| **卡牌种类** | 角色 / 场地 / 事件。 |
| **能力** | 卡面文字。关键字能力（《撤步》等）和带时机的能力（【登场时】等）见第 10、11 节。 |
| **触发** | 这张卡作为生命卡被翻开时可以发动的效果（见第 9 节）。发动与否由玩家决定。 |
| **能量产出**（右下角圆点） | 这张卡**在能量线上**时产生的能量，圆点数就是数量，圆点颜色就是能量颜色。圆点旁有“+”的卡，表示它有能力可能增加产出。**前线上的卡不产生能量。** |
| **BP**（战斗力） | 主要在战斗中比较。角色的 BP 被能力降到 **0 或以下时退场**。BP 旁有“+”表示它有能力可能提高 BP。 |
| **突进**（Raid） | 只有部分角色有，见 8.3.2。 |
| **稀有度 / 卡号** | 同一卡号最多放 4 张。 |

### 2.2 角色卡

- 用来**攻击**和**阻挡**。
- 打出时以**休息状态**（横放）放到**前线或能量线**。
- 之后可以在移动阶段移动（见 8.2）。

### 2.3 场地卡

- 在场上时一般提供支援效果。
- 打出时以**休息状态**放到**能量线**，**不能放到前线，也不能移动**。

### 2.4 事件卡

- 使用后发动卡面能力，结算完放进**场外**。
- 事件不放到场上，所以前线和能量线满了也能使用。

### 2.5 AP 卡

- 每名玩家 3 张，放在 AP 区，不放进牌组。
- **支付 1 AP** = 把 1 张**活跃**的 AP 卡转为**休息**。

## 3. 场地区域

```
┌──────────────────────────────────────────────┐
│ 生命区 │        前线（最多 4 张）       │ 卡组  │
│ (开局  ├───────────────────────────────┤       │
│  7 张) │       能量线（最多 4 张）       │ 阶段栏 │
├────────┼───────────────────────────────┼───────┤
│ 移除区 │        AP 区（最多 3 张）       │ 场外  │
└──────────────────────────────────────────────┘
```

| 区域 | 说明 |
| --- | --- |
| **前线** | 放角色，角色在这里攻击和阻挡。**最多 4 张角色**。场地不能放到前线。 |
| **能量线** | 放角色和场地，**最多 4 张**（种类任意）。只有能量线上的卡产生的能量才能用来满足所需能量。 |
| **场上** | 前线和能量线合称“场上”。 |
| **生命区** | 代表生命。开局时背面朝下放 7 张。 |
| **AP 区** | 放 AP 卡，最多 3 张。 |
| **卡组放置处** | 放自己的牌组（背面朝上）。 |
| **场外** | 使用过的事件、退场的角色和场地、翻开后的生命卡都正面朝上放在这里。 |
| **移除区** | 被要求“置于移除区”的卡正面朝上放在这里，基本上就此离开游戏。 |

**线满了怎么办**：要把卡放到已经有 4 张的线上时（打出、移动、突进后上前线、效果登场都一样），**必须先从那条线上选 1 张卡置于移除区**，腾出位置后再放。场上的卡只有在线满时才能这样置于移除区。

## 4. 组牌规则

每名玩家需要：

- **主牌组正好 50 张**，并且满足：
  - **同一作品代码**：卡号前段相同。本游戏只有明日方舟（`ARK`）。
  - **同一卡号最多 4 张**。异画卡（同卡号不同插画）合计算在一起。
  - **【特殊】【色彩】【最终】三种触发，每种各自最多 4 张**。例如卡 A、卡 B 都是【特殊】触发，A 和 B 合计不能超过 4 张。其它触发不限。
- **AP 卡 3 张**。

---

## 5. 开局准备

1. 双方洗牌，牌组放在卡组放置处。
2. 决定先手（玩家一）和后手（玩家二）。规则书写的是猜拳等方式，本游戏随机决定。
3. 双方从牌组顶抽 7 张作为起手牌。
4. **换牌**：每人可以重抽一次起手牌：把 7 张起手牌放到牌组底，再从顶部抽 7 张，然后洗牌。**先手先决定**，后手再决定。
5. 双方从牌组顶拿 7 张，**不看**，背面朝下放进生命区。
6. 先手开始第一个回合。

---

## 6. 胜利条件

满足下面任意一条就获胜：

- **对手生命区没有卡了。** 受到伤害时，要等这次伤害翻开的生命卡全部检查完触发，才判断生命区是否为空（见 8.4.4）。
- **对手在自己的起始阶段因为牌组没有卡而无法抽卡。**

另外，本游戏允许**认输**（对局中的「效果」菜单），认输的一方立即判负。

---

## 7. 活跃与休息

- 场上的角色和场地，**竖放是活跃**，**横放是休息**。
- 角色和场地**打出时都是休息状态**（除非能力另有说明）。
- **只有活跃的角色才能攻击或阻挡**，攻击或阻挡时要转为休息。
- AP 卡同样有活跃和休息：支付 AP 就是把活跃的 AP 卡转为休息。

## 8. 回合流程

先手先进行回合，之后双方轮流。每个回合依次是：

**① 起始阶段 → ② 移动阶段 → ③ 主要阶段 → ④ 攻击阶段 → ⑤ 结束阶段 → 对手的回合开始**

### 8.1 起始阶段

按顺序进行：

1. 写着“直到我方的下一个回合开始时”之类的效果结束。
2. 把自己所有**休息**的卡（角色、场地、**AP 卡**）转为**活跃**。
3. 把 AP 区的 AP 卡补到当前回合规定的张数，新放的 AP 卡是活跃状态：

   | | 第 1 回合 | 第 2 回合 | 第 3 回合起 |
   | --- | --- | --- | --- |
   | 先手 | 1 张 | 2 张 | 3 张 |
   | 后手 | 2 张 | 2 张 | 3 张 |

   “第 N 回合”指这名玩家自己的第 N 个回合。

4. **抽 1 张卡。**（先手的第 1 个回合不抽。）牌组没有卡、抽不了时，这名玩家**判负**。
5. **额外抽卡**：每回合 1 次，可以支付 1 AP 再抽 1 张。先手第 1 回合也可以额外抽卡。

### 8.2 移动阶段

- 可以把任意张角色**从能量线移动到前线**。
- **不能**把角色从前线移到能量线，**除非它有《撤步》**。
- **场地不能移动。**
- **所有移动同时进行**：先选好要移动的卡，再一起移动。
- 目的地的线放满 4 张时，**每移进去 1 张，就要先从那条线选 1 张置于移除区**。移动阶段以外由效果造成的移动也一样处理。

### 8.3 主要阶段

主要阶段里，下面 A、B 两类行动可以做任意多次，顺序随意。

#### A：使用卡牌

使用任何一张手牌都要满足两个条件：

1. **所需能量**：能量线上产生的、与这张卡同颜色的能量总数 ≥ 卡上的所需能量。
2. **支付 AP**：把与消费 AP 相同数量的活跃 AP 卡转为休息。

> 例：能量线上有 1 张产生 1 点绿色能量的卡、1 张产生 2 点绿色能量的卡，合计 3 点绿色能量。手牌里所需能量为 0、3 的绿色卡都能用，所需能量为 5 的不能用。前线上的卡产生的能量不算。

##### 8.3.1 打出角色卡

满足所需能量、支付 AP 后，把角色以**休息状态**放到**前线或能量线**。线满时先把那条线的 1 张卡置于移除区。

##### 8.3.2 突进

有【突进】的角色，除了正常打出，还可以**突进**：宣言突进，然后把它**叠在一张符合指定的、自己场上的角色上**。

- 指定写在突进标志右边：
  - `〈ABC〉`：卡名为 ABC 的角色。
  - `[XYZ]`：有“特征：XYZ”的角色。
- 被叠的角色**本身不能有【突进】**。
- 从手牌突进时，同样要**满足所需能量并支付 AP**。
- 能力写“登场”时**不能**拿来突进；只有写着“进行突进”的能力才可以。

突进的处理顺序：

1. 把这张卡叠到指定角色上，下面的卡称为**突进源**。
2. 原来那张角色身上受到的效果全部失效，它自己的能力也失效。
3. 如果那张角色是休息状态，转为**活跃**。
4. 如果那张角色在能量线上，可以把它**移动到前线**。
5. 突进上去的这张卡的【登场时】能力发动。

有【突进】的卡也可以正常打出，但正常打出时，【突进】那一段文字里的能力不生效。

##### 8.3.3 打出场地卡

满足所需能量、支付 AP 后，把场地以**休息状态**放到**能量线**，线满时先把 1 张卡置于移除区。**场地不能打到前线。**

##### 8.3.4 使用事件卡

满足所需能量、支付 AP 后，发动事件的能力；结算完毕把事件放进**场外**。前线、能量线满了也能使用。

#### B：发动场上卡牌的【启动主要】能力

场上卡牌写着【启动主要】的能力，满足条件并支付费用后就能发动。费用写在 〔 〕 里，可能有：

| 费用 | 意思 |
| --- | --- |
| 〔转为休息状态〕 | 把这张活跃的卡转为休息 |
| 〔将 N 张手牌置于场外〕 | 从手牌选 N 张放进场外 |
| 〔支付 N AP〕 | 支付 N AP |
| 〔将此卡牌退场〕 | 让这张卡退场 |

写了多项费用的，**全部支付**才能发动。

- **「每回合1次」**：这个能力每回合只能发动 1 次，**场上每一张卡各自计算**。一张卡离开场上又重新登场后，会被当成另一张卡，可以再发动 1 次。
- 卡面上写“〈某卡名〉的此效果 1 回合只能发动 1 次”的，按卡名合计，同名卡共享这 1 次。

### 8.4 攻击阶段

用前线的角色攻击对手。一次攻击都不进行，攻击阶段就直接结束。

- 一次只用 1 张角色攻击；攻击结束后，还有活跃的角色的话可以接着攻击。
- **只能攻击对手玩家本身**（有《瞄准攻击》的角色例外）。
- **攻击阶段不能使用卡牌。**
- **攻击不消耗 AP。**

每次攻击按下面的步骤进行。

#### 8.4.1 宣告攻击

选择自己**前线上 1 张活跃的角色**，把它**转为休息**，宣告攻击对手。

- 有《瞄准攻击》的角色，可以改为指定对手前线的 1 张角色攻击（见第 10 节）。
- 攻击角色的【攻击时】能力、以及其它“攻击时”发动的能力在这时结算。

#### 8.4.2 宣告阻挡

被攻击的玩家可以选择用自己**前线上 1 张活跃的角色**阻挡，阻挡的角色转为休息。

- **没有阻挡**：结算攻击角色“没有被阻挡时”的能力，然后攻击打到玩家（8.4.4）。
- **有阻挡**：结算阻挡角色的【阻挡时】能力，然后阻挡的角色成为“被攻击的角色”，进入战斗（8.4.3）。
- 被《瞄准攻击》指定的角色**不算阻挡**，所以它的【阻挡时】能力不发动，但战斗照常发生。

#### 8.4.3 攻击角色（战斗）

比较双方 BP。**战斗本身不会改变双方 BP。**

**A. 攻击角色 BP ≥ 被攻击角色 BP**：攻击方胜。

1. 被攻击的角色**退场**。
2. 结算它的【退场时】能力，以及其它“退场时”发动的能力。
3. 结算攻击方“战斗胜利时”的能力，例如《冲击1》给对手 1 点伤害。

**B. 攻击角色 BP < 被攻击角色 BP**：被攻击方胜。

1. 结算攻击方“攻击且战斗失败时”的能力。
2. 结算对手“战斗胜利时”的能力。
3. **攻击的角色输了也不退场。**

**BP 相同时，攻击方获胜。**

A、B 处理完后战斗结束：结算“战斗结束时”的能力，“仅在这次战斗中”生效的效果失效。

#### 8.4.4 攻击玩家（受到伤害）

攻击没有被阻挡时，给对手 **1 点伤害**。攻击角色有《伤害2》时改为 2 点；《伤害+N》再加 N 点。

**受到伤害时**：

1. **造成伤害的一方**选择对手生命区的卡，伤害几点就选几张。生命区剩下的卡比伤害少时，全部选上。
2. 受到伤害的一方把这些卡**翻开**，逐张**检查触发**（第 9 节）。
3. 每张生命卡处理完触发后放进**场外**。没有触发的卡也放进场外。
4. 一次翻开多张生命卡时，受伤一方可以**自选顺序**逐张处理：一张发动、结算、进场外后，再处理下一张。
5. **全部触发检查完以后**，受伤一方的生命区没有卡了，就**输掉**对局。

#### 8.4.5 继续或结束

还想用别的角色攻击，就回到 8.4.1；否则结束攻击阶段。

### 8.5 结束阶段

按顺序进行：

1. “结束阶段开始时”发动的能力在这时发动并结算。
2. 把自己场上所有**休息**的**角色和场地**转为**活跃**。**休息的 AP 卡保持休息**，下回合起始阶段才恢复。
3. **手牌超过 8 张**时，选 8 张留下，其余**置于移除区**（不是场外）。
4. “本回合中”的效果失效。

全部做完后，轮到对手的回合。

## 9. 触发

生命卡因受到伤害被翻开时，如果卡上有触发，**这张卡的主人可以选择发动**，不发动也可以。发动后结算效果，然后这张卡放进场外；除非效果让它进入手牌或场上，比如【获得】【突进】。

本卡池共有 7 种触发，效果如下：

| 触发 | 效果 | 本卡池张数（按卡号） | 组牌限制 |
| --- | --- | --- | --- |
| **【抽卡】** | 抽 1 张卡。 | 46 | 无 |
| **【获得】** | 这张卡加入手牌。 | 21 | 无 |
| **【激活】** | 选择我方场上 1 张角色，转为活跃，本回合 BP+3000。 | 38 | 无 |
| **【突进】** | 这张卡加入手牌；或者满足所需能量时，用它**进行突进**（不支付 AP）。 | 16 | 无 |
| **【特殊】** | 选择对方前线 1 张角色退场。 | 11 | 每种最多 4 张 |
| **【色彩】** | 每张卡不同，见下表。 | 12 | 每种最多 4 张 |
| **【最终】** | 我方生命区没有卡时，把我方牌组顶的 1 张卡置于生命区。 | 5 | 每种最多 4 张 |

**【色彩】触发**（各颜色不同）：

| 效果 | 张数 |
| --- | --- |
| 选择对方前线 1 张 BP 不高于 2500 的角色退场。 | 3 |
| 选择对方前线 1 张 BP 不高于 3500 的角色，放回手牌。 | 3 |
| 选择对方前线 1 张角色转为休息；该角色**下一次转为活跃无效**。 | 4 |
| 从我方场外把 1 张所需能量不高于 2、消费 AP 为 1 的紫色角色，以**活跃**状态登场到我方前线。 | 2 |

补充：

- 触发里的“对方”指**造成这次伤害的玩家**，也就是正在攻击的一方。
- 【最终】是在这张卡离开生命区后才判断“我方没有生命卡”。所以它是**最后一张生命卡**时，可以从牌组顶补 1 张回生命区，避免输掉。
- “下一次转为活跃无效”：这张角色下一次本来要转为活跃时（通常是它主人起始阶段的“全部转为活跃”），保持休息，之后恢复正常。

## 11. 能力的时机、费用与条件

### 11.1 发动时机

| 本卡池写法 | 英文原名 | 意思 |
| --- | --- | --- |
| **【登场时】** | When Played | 这张卡登场到场上时发动。包括：从手牌打出、突进、由触发突进、由能力让它登场。对手回合中登场也会发动。 |
| **【退场时】** | When Sidelined | 这张卡**退场**时发动（“退场”的定义见 12.4）。 |
| **【攻击时】** | When Attacking | 这张角色攻击时发动。 |
| **【阻挡时】** | When Blocking | 这张角色阻挡时发动。 |
| **【启动主要】** | Activate: Main | 我方主要阶段中，支付费用发动（见 8.3 B）。 |
| **【我方的回合中】** | During Your Turn | 在我方回合中一直生效。 |
| **【对方的回合中】** | During Opponent's Turn | 在对方回合中一直生效。 |

卡面文字里还常见这些时机：“当此角色从能量线移动至前线时”“当攻击阶段结束时”“当主要阶段结束时”“当我方一次受到 2 点或更多伤害的场合”“当此卡牌置于场外时”等，照字面意思在那个时间点发动。

### 11.2 费用（〔 〕）

〔转为休息状态〕〔将 1 张手牌置于场外〕〔支付 1AP〕〔将此卡牌退场〕，见 8.3 B 的表。写了几项就要全部支付。

### 11.3 条件

| 写法 | 意思 |
| --- | --- |
| **〔前线中存在的场合〕** / **「前线中存在的场合」** | 这张卡在前线上时才生效或才能发动。 |
| **〔能量线中存在的场合〕** / **「能量线中存在的场合」** | 这张卡在能量线上时才生效或才能发动。 |
| **「每回合1次」** | 每回合只能发动 1 次，场上每张卡各自计算。 |
| “……的场合” | 条件成立才生效；不成立时，这部分没有效果。 |
| “只有在……的场合才能使用” | 写在事件上，条件不成立时不能使用这张事件。 |

条件全部满足，能力才发动。

### 11.4 常见用语

| 用语 | 意思 |
| --- | --- |
| **选择** | 由能力的主人从符合条件的卡中挑选。写“最多 N 张”时可以少选，甚至不选；写“N 张”时有几张选几张。 |
| **可以……** | 可选的效果，由能力的主人决定做不做。“这样做的场合，……”只有前面做了才会发生。 |
| **本回合中** | 效果持续到这个回合的结束阶段（8.5 第 4 步）。 |
| **直到我方的下一个回合开始时为止** | 效果持续到我方下一个起始阶段的第 1 步。 |
| **原本的 BP** | 卡面印着的 BP，不算任何增减。 |
| **登场** | 把卡放到场上（打出或由效果放上）。 |
| **置于场外 / 置于移除区** | 把卡放进场外 / 移除区。注意“置于场外”**不算**“退场”（见 12.4）。 |
| **放回手牌** | 把场上的卡放回主人的手牌。 |
| **确认卡组最上方的 N 张** | 只有自己看；剩下的卡按能力处理，常见的是“自选顺序置于卡组最下方”。 |
| **公开** | 给对手看过后再处理。 |

## 12. 通用规则

### 12.1 多个能力同时发动

- 同一时间发动的多个能力，由它们的主人**自选结算顺序**。
- 双方的能力同时发动时，**正在进行回合的玩家先**把自己的全部结算完，然后才轮到另一方。
- 结算中又发动了新能力的，新能力加入还没结算的那些能力里，一样可以自选顺序。

### 12.2 BP 降到 0 或以下

场上的角色 BP 被能力降到 **0 或以下**时，**立即退场**。

### 12.3 有突进源的角色离开场上

突进过的角色（下面压着突进源）要去场上以外的地方时，例如被放回手牌或置于移除区：**只有最上面那张**去那个地方，**下面的突进源全部放进场外**。突进源放进场外**不算退场**。

### 12.4 “退场”的定义

只有下面三种情况，场上的卡进入场外才叫**退场**，会发动【退场时】：

- 在**战斗**中输掉；
- **BP 降到 0 或以下**；
- 能力写明**让它“退场”**。

能力写“**置于**场外”，或卡去了手牌、移除区等场外以外的地方，都**不算**退场。

### 12.5 “改为”（替换）

写着“{A}……的场合，{B}改为……”的能力：条件满足时，用 B 那段文字**替换** A 那段再执行。

> 例：“选择对方前线最多 1 张角色转为休息……场上有 6 张或更多特定特征的卡时，**改为**选择对方前线 1 张角色，并把它和对方能量线上的所有角色转为休息。”条件不满足就按前半段执行，满足就按后半段执行。

本卡池里还有两类常见的“改为”：

- **伤害替换**：例如“当我方一次受到 2 点或更多伤害的场合，可以改为受到 1 点伤害”。在伤害发生前询问。
- **退场替换**：例如“……退场的场合，可以改为将此角色退场”“……可以改为将突进源置于场外”。在角色将要退场时询问，选择替换后原来那张角色**不退场**。

## 13. 本游戏的实现说明

这一节说明本项目怎样执行上面的规则，以及和规则书写法的差别。

### 13.1 自动结算

- 全部 194 个卡号的能力都由引擎**自动结算**：时机、费用、选择、持续效果、替换效果都按卡面执行。需要玩家决定的地方（选目标、“可以”、排顺序、选模式）会在操作栏提问。
- 卡牌放大图里仍保留「卡牌效果」手动操作，例如转为休息/活跃、BP±1000、抽卡、退场等，用来处理特殊情况。每一次手动操作都会记入公开的对局日志。
- 手动“退场”不会被替换效果拦下（规则上替换只针对战斗和效果）。

### 13.2 和规则书写法不同或规则书没写清的地方

| 情况 | 本游戏的处理 |
| --- | --- |
| 先手怎么决定 | 随机决定。 |
| 有《撤步》的角色移到已满的能量线 | 规则书允许选择和能量线上的角色**交换位置**。本游戏只提供“把能量线 1 张卡置于移除区”这一种方式，不能交换。 |
| 伤害选择生命卡 | 由攻击方点选；操作栏也有“随机选择”。 |
| 触发没有合法目标 | 可以发动，但效果为空（例如对方前线没有角色时的【特殊】），这张卡照常进入场外。 |
| 从生命区突进（【突进】触发） | 要满足所需能量，**不支付 AP**。 |
| 抽卡时牌组为空 | 规则书只规定了“起始阶段无法抽卡则判负”；其它时候抽不到就不抽，不判负。 |
| 认输 | 对局中「效果」菜单里的「认输」，立即判负。 |
| 效果让生命区清空 | 例如霜星把生命卡置于场外。生命区一空就判负，和受到伤害清空生命区一样。 |

### 13.3 少数卡牌的近似处理

下面几张卡在极少见的情况下和卡面有细微出入，平时对局不受影响：

- **爱国者**（ARK-2-043）「不会受到 BP 降低效果的影响」：它登场前本回合已经生效的 BP 降低仍然算数；它离场后，之前被挡下的降低也不会恢复。
- **碎骨**（ARK-1-007）「场外的此卡牌所需能量减少 2」：只对黄色卡自己的“从场外选择”生效；【色彩】触发从场外登场时，仍按卡面印的所需能量判断。
- **阿丽娜**（ARK-2-027）交换位置时，不会触发“移动至前线/能量线时”。
- **霜星**（ARK-1-027）、**切尔诺伯格**（ARK-2-055）「以活跃状态登场」：实现为登场时转为活跃，结果相同。

### 13.4 联网对战

- 对手的手牌、双方牌组只显示张数，背面朝下的生命卡不会发送给对手，所以无法通过网页偷看。
- 掉线后 30 秒内重新连接，可以回到原来的对局。
